# 新手运行说明：值班问题与处理方案库

## 启动网页

1. 在 Codex 中打开本项目的 `web-tool` 文件夹。
2. 打开终端后运行 `npm run dev`。
3. 浏览器访问终端显示的地址，通常是 `http://localhost:3000`。

## 使用方式

- 首页可查看问题数量、分类数量和最近收录的问题。
- 点击“查看全部问题”可按标题、关键词、处理思路搜索，也可按分类筛选。
- 点击任意问题可查看详情，并复制处理思路。
- 点击“新增问题”填写表单；勾选匿名化确认后保存。数据仅保存在当前浏览器。
- 不得录入患者姓名、住院号、联系方式、照片、检查单截图或任何可识别患者身份的信息。
- 本工具仅供个人学习和工作复盘参考，不替代正式诊疗决策、院内制度或上级医师意见。

## 停止网页

在正在运行服务器的终端中按 `Ctrl + C`。

## 修改页面

打开 `src/app/page.tsx`，修改文字后保存；浏览器会自动刷新。

## 常见报错

- `npm` 找不到：关闭并重新打开 Codex；若仍存在，请重新安装 Node.js LTS，并勾选“加入 PATH”。
- 地址打不开：确认终端仍在运行 `npm run dev`，再复制终端显示的完整地址。
- 修改后没变化：保存文件，并刷新浏览器；仍无效时停止服务后重新运行 `npm run dev`。
